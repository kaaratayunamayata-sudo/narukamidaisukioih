# ブロパス配布 第1回 陣取り争奪戦

横6×縦5（30マス）の「ブロパスの的」から陣地を選び、同じマスを狙った時だけミニゲーム「お肉ピッタリ半分」で争奪戦をするイベントサイトです。

## 構成

| 場所 | 役割 |
|---|---|
| `public/` | フロント（index.html / style.css / app.js）。秘密情報は一切なし |
| `netlify/functions/api.mjs` | 唯一のバックエンドAPI（`/api`）。所有権・勝敗判定・認証・チャット・管理操作をすべてここで処理 |
| `netlify/functions/lib/players.mjs` | **初期参加者29人の登録データ**（テスト参加者は管理画面から追加し、ゲームデータ側に保存されます） |
| `test/logic.test.mjs` | 対戦ロジックのテスト（`node test/logic.test.mjs`） |

データベースは **Netlify Blobs**（Netlifyに標準内蔵・外部アカウント不要・設定不要）を使用します。
Firebase/Supabaseの登録やAPIキーは不要です。保存先は game / chat / presence / sessions の4つ。書き込みは楽観的排他制御（etag）で、同時に同じ空きマスを押しても1人だけが確保できます。

「リアルタイム」は約1〜2秒間隔の同期（対戦中は0.7秒）で実現しています。

## 公開手順

1. このフォルダ全体をGitHubリポジトリにpush（または Netlify の「Deploy manually」にフォルダをドラッグ）。
2. Netlify で **Add new site → Import from Git**（ビルドコマンドは空、設定は `netlify.toml` が自動で読み込まれます）。
3. 管理者パスワードは `netlify/functions/api.mjs` 内の `ADMIN_PASSWORD`（現在は `narukami`）です。環境変数 `ADMIN_PASSWORD` は使いません。変えたい時はこの1行を書き換えて再デプロイしてください。（任意）環境変数 `ADMIN_SECRET` に管理者トークン署名用のランダム文字列を入れるとより安全です。
4. 再デプロイ（Deploys → Trigger deploy）。
5. 公開URLを参加者へ共有。

> ドラッグ&ドロップ公開ではFunctionsの依存インストールが走らない場合があります。Git連携でのデプロイを推奨します。

## 管理者の使い方

- ログイン画面またはメイン画面右下の「運営ログイン」から、管理者パスワードで認証（8時間有効）。
- **イベントは初期状態で「開始前」です。管理画面の「イベント開始」を押すまで陣地の確保はできません。**
- **テスト参加者**: 管理画面の「参加者」タブ上部で、名前を入力して追加（空欄なら「テスト1」のように自動命名、まとめて5人も可。最大30人）。ログイン画面の一覧に出るので、本番と同じ操作でテストできます。「このアカウントで参加」ボタンですぐ入れて、不要になったら「削除」（陣地・対戦も消えます）。全体の集計（進行率・オンライン率）には含まれません。「すべて初期化」してもテスト参加者は残ります。
- できること: イベント開始/終了、参加者の停止/解除・強制ログアウト・陣地解放、マスのリセット／全初期化、争奪戦の取消・勝者指定、対戦結果の確認、チャットの削除・通報確認・お知らせ送信。

## ルール

- 空きマス → そのまま確保。誰かが確保済みのマス → その所有者と争奪戦。**ただし所有者がオンラインの時だけ**挑戦できます（オフラインの人のマスは奪えません。オンライン＝直近30秒以内に接続あり）。
- 1人1マス。空きマスを選び直すと移動、争奪戦に勝つと元のマスは空きます。
- 争奪戦: 両者が「準備OK」→ 3-2-1 → お肉が0→100%へ5秒で伸びる → 途中（30%以降）は隠れる → STOPで止めた位置が50%に近い方が勝ち。位置は**サーバー時刻から計算**され、クライアントの申告は使いません。同点は再戦。時間切れは100%扱い。
- 相手が120秒準備しない場合は不戦勝を申請可能。防衛者は降参可能。
- 勝者がマスを獲得、敗者は獲得できません。

## 仕様上の注意

- アカウントにパスワードはありません（仕様どおり「選択＋確認」のみ）。同一アカウントの同時参加はサーバーが拒否しますが、他人のアカウントを選ぶこと自体は技術的に防げません。不正は管理画面の停止機能で対応してください。
- 通信遅延の差はサーバー受信時刻で判定されるため、ごく僅かに有利不利が出ます。
- Netlifyの無料枠の関数呼び出し数に注意（29人が1時間つなぐと約5万リクエスト）。
