# BRO PASS MARBLE GRAND PRIX（Supabase不要版）
1. このフォルダごとGitHubにアップロード
2. Netlifyで「Import from Git」→ そのまま Deploy（設定不要。package.json と netlify.toml が自動で使われます）
3. 管理画面：公開URL/#admin　パスワードは narukami
   変更する場合は Netlify の Site settings > Environment variables に ADMIN_PASSWORD を追加して再デプロイ
※ ドラッグ&ドロップ公開では Functions が動かないので、必ずGit連携で公開してください
